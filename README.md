# Science Studio

5th Grade Science Studio for the 1st 9 weeks.

Includes:
- 45 daily lessons
- Student dashboard
- Teacher dashboard
- Interactive labs and simulations
- Vocabulary posters
- STAAR-style review
- Digital assessment
- Student reflection and goal-setting tool
- Instructional Officer guided demo page

Main guided demo page:
/instructional-officer-demo

Production start command:
gunicorn app:app
