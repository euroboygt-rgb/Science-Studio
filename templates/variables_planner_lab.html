Teacher Teach: Variables in a Fair Test

Teacher Script: “A fair test changes only one thing on purpose. That one thing is the independent variable. The thing we measure is the dependent variable. Everything we keep the same is a controlled variable.”
Independent Variable:
What I change
Dependent Variable:
What I measure
Controlled Variables:
What stays the same

Part 1: Quick Visual Vocabulary

Independent Variable

The one thing changed on purpose.

Example: Ramp height

Dependent Variable

The result measured or observed.

Example: Distance traveled

Controlled Variables

The things kept the same.

Example: Same car, surface, start line
