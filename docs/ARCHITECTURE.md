# Science Studio Architecture

## Main Sections

- Dashboard
- Calendar
- Curriculum
- Lessons
- Labs
- Interactive Notebook
- Assessments
- STAAR Center
- AI Tools
- Settings

## Dashboard

The dashboard is the teacher's home page.

It should answer:

"What do I need to teach today?"

## Labs

The first major feature will be the Interactive Online Lab Creator.

Each lab contains:

- Title
- TEKS
- Materials
- Safety
- Student directions
- Data table
- CER response
- STAAR-style questions
